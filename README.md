# WB CLI

Command-line tool for interacting with the wildberries.ru marketplace

## Installation

```bash
go install github.com/vlad-golang/wb-cli@latest
```

## Examples

```bash
wb-cli -help
```

## Skill

```bash
npx skills add https://github.com/vlad-golang/wb-cli --skill wb-cli
```

## Required

```bash
Google Chrome
```
